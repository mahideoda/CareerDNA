# CareerDNA

CareerDNA is an AI-powered interview readiness platform designed to help students analyze resumes, evaluate interview preparedness, and receive recruiter-style insights.

## Features
- Resume PDF upload
- AI-inspired readiness scoring
- ATS compatibility analysis
- Recruiter insights
- Futuristic dashboard UI
- FastAPI backend
- Responsive frontend

## Tech Stack
Frontend:
- Next.js
- TypeScript
- TailwindCSS
- Framer Motion

Backend:
- FastAPI
- Python
- PyMuPDF
